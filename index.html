🗄️ Configurar Supabase

De aquí sale toda la lista de festivales — es la base de datos que usa la app. Ya viene rellenada con la que usáis ahora; solo tendrías que cambiarla si algún día migras a otro proyecto de Supabase. Se guarda en este dispositivo.

🔑 Configurar Perplexity

El Asistente IA usa la API de Perplexity para buscar información de festivales. Necesitas tu propia clave: se guarda solo en este dispositivo, nunca se envía a ningún sitio salvo directamente a Perplexity.

  1. Ve al portal de API: console.perplexity.ai.
  2. Regístrate — no hace falta introducir ningún método de pago, pulsa "Finalizar" o sáltatelo si te lo pide.
  3. Ve a "Claves API" (API Keys) y pulsa "Crear nueva".
  4. Copia la clave (empieza por pplx-) — solo se muestra una vez, así que guárdala bien.
  5. Pégala arriba, en el campo de "Tu clave", y pulsa "Guardar".

Opcional: personaliza el texto exacto que se le manda a la IA, y su temperatura/límite de respuesta, para el Asistente y para el Resumen.
